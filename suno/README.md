# Агенты для создания хитов в Suno

В `.claude/agents/` лежат 4 агента Claude Code. Они работают как команда:

| Агент | Что делает |
|---|---|
| `music-style-analyst` | Разбирает звучание артиста/песни: жанр, BPM, гармонию, инструменты, продакшн, вокал, структуру, хуки → английские теги для Suno |
| `lyrics-analyst` | Разбирает темы, образы, рифмы и лексику артиста и пишет **оригинальный** текст без ИИ-клише |
| `suno-prompt-engineer` | Собирает готовый промт: Style, Exclude Styles, Lyrics с метатегами, настройки |
| `humanizer-critic` | Ищет всё, что выдаёт ИИ, ставит оценки хитовости и возвращает исправленную финальную версию |

## Как пользоваться

Весь конвейер одной командой:

```
/suno-hit Zivert — песня про летний роман на море, по-русски, грустно-танцевальная
/suno-hit Arctic Monkeys AM era — English, about a late-night phone call
```

Можно вызвать агента по отдельности:

```
Попроси music-style-analyst разобрать звучание альбома «Хоп-хей» Ленинграда
Попроси humanizer-critic проверить мой промт: <вставь промт>
```

Готовые промты сохраняются в `suno/prompts/`.

## Как добиться «человечного» звучания

- В Style описывай звук словами — имена артистов Suno блокирует.
- Добавляй живые дескрипторы: `live band recording, room mics, analog warmth, tape saturation, natural dynamics, breathy vocals`.
- В Exclude Styles убирай стерильность: `robotic vocals, overcompressed, sterile, glossy, perfect quantization`.
- В тексте: конкретные детали (имена, места, время), неточные рифмы, строки разной длины, разговорные вставки, никаких «неонов, теней и эха».
- Генерируй 4–6 вариантов, выбирай лучший, дорабатывай через Replace Section / Extend.
- Для максимальной живости: вытащи стемы и перезапиши вокал или один живой инструмент, сведи вне Suno.
